# ギャラリー差し替え写真の受け皿

このフォルダに差し替え用の写真を入れてください。入れたあとで「ギャラリーの写真を入れた」と伝えれば、
サイト用に変換（WebP・サイズ調整）してバレル加工ページのギャラリーへ反映します。

## 写真の仕様
- 比率: 4:3 の横長（ギャラリーの枠が 4:3 固定のため、違う比率は上下か左右が切れます）
- サイズ: 横 1600px 以上を推奨
- 形式: JPG / PNG / HEIC どれでも可（こちらで WebP に変換します）

## ファイル名の付け方
差し替える位置の番号を先頭に付けてください（例: `02_新しい写真.jpg`）。
番号のない写真は、ギャラリーの末尾に追加するものとして扱います。
